# User Stories - GiftLink Project

## Epic 1: User Registration and Authentication

### US-001: User Registration
**As a** new user  
**I want to** register for an account  
**So that** I can list items and contact other users  
**Status:** New  
**Label:** new

### US-002: User Login
**As a** registered user  
**I want to** log in to my account  
**So that** I can access my profile and listed items  
**Status:** New  
**Label:** new

### US-003: User Profile Management
**As a** logged-in user  
**I want to** edit my profile information  
**So that** other users can contact me  
**Status:** Backlog  
**Label:** backlog
